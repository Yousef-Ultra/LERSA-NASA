# LERSA — Linear Electromagnetic Regenerative Shock Absorber & 3D Lunar Digital Twin

**Challenge:** Lunar Landing Site Navigator (NASA Space Apps Challenge 2026)  
**Team Member:** Yousef Al-Shalwy (Mechanical Engineering, Al-Baha University — Riyadh Local Event)

## Overview
LERSA is a contactless, energy-harvesting landing and mobility architecture paired with an interactive 3D physics Digital Twin (`LERSA1411.html`) designed to enable safe lunar exploration inside steep South Pole craters and Permanently Shadowed Regions (40 K / −233 °C).

## How to Run
1. Download `LERSA1411.html` from this repository.
2. Open it directly in any modern web browser (Chrome, Edge, Safari, Firefox) with an active internet connection to load Three.js and Chart.js libraries.

## NASA Open Data Used
- **NASA LRO LOLA:** South Pole crater elevation and 35°–42° slope parameterization.
- **NASA LRO Diviner:** 40 K (−233 °C) Permanently Shadowed Region thermal boundary conditions.
- **NASA LCROSS:** Volatile and water-ice concentration zones.
- **NASA VIPER:** Baseline rover mobility and regolith bearing pressure benchmark (0.20 m/s, ≤ 15 kPa).
